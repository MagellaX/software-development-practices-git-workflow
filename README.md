# Git workflow demonstration

A two-page HTML project created locally before its public GitHub repository.

The history demonstrates initial and updated content, work on `feature`, an explicit merge into `main`, `.gitignore`, and a temporary change undone with `git revert`.

Open `index.html` in a browser. See `git_commands.txt` for the commands and their explanations. Ignored examples are `debug.log` and `temp/scratch.txt`.
